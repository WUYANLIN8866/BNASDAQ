# 每日市場分析「美元與台幣視角」的寫法（fx 欄位）

站主 2026-11-27 要求：用台灣投資人的視角回答「美元計價資產同時下跌時，是不是美元在急拉？換算成台幣後是賺還是賠？」
每一版（早上版、下午版、晚上版，以及盤前／盤中／盤後大漲大跌的更新）都要有；沒有就發布不了。

## 分工
| 誰 | 做什麼 |
|---|---|
| 程式（scripts/publish_daily.py → scripts/daily_fx.py） | 發布當下從本站即時快照現抓、現算全部數字，寫進 `fx.asof`、`fx.data`。報告裡自己填的 asof、data 會被覆寫 |
| 寫報告的人或 AI | 只寫判斷與說明文字：`scenario`、`basis`、`twd_reasons`、`holders`、`foreign` |
| 網頁（daily.html） | 一句話結論、數據表、台幣報酬（美元資產漲跌＋美元兌台幣漲跌）、緩衝／雙殺的白話判斷，都由網頁用 fx.data 現算 |

## 步驟
1. 先跑 `python3 scripts/daily_fx.py` 看現在的數字（美元指數、美元兌台幣、10 年期殖利率、黃金、西德州原油、那指 100、標普 500、費半、台股加權）。
2. 依數字選一個情境（只能選一個）：
   | scenario | 名稱 | 條件 |
   |---|---|---|
   | `usd_spike` | 美元急拉 | 美元指數急漲＋殖利率上升＋股票與原物料同跌 |
   | `cash_panic` | 恐慌搶現金 | 美元指數漲＋黃金也跌＋股票與原物料同跌 |
   | `usd_exit` | 資金撤離美元資產 | 美股跌＋美元指數也跌 |
   | `none` | 無明顯訊號 | 以上都不符合（網頁會寫「今天不是美元主導」） |
3. 在報告 JSON 加上：
```json
"fx": {
  "scenario": "none",
  "basis": ["美元指數單日 +0.12%，不算急漲", "那指 100、標普 500 都上漲，沒有股票與原物料同跌"],
  "twd_reasons": ["外資買超台股 ○○ 億元，匯入推升台幣（證交所，11/27）"],
  "holders": {"etf": "一句話", "usd": "一句話", "tw": "一句話"},
  "foreign": {"net": "買超 123.4 億元", "date": "11/27", "src": "證交所"}
}
```

## 規則
- `basis`：寫出判斷依據是哪幾個數據（引用步驟 1 的數字）。
- `twd_reasons`：台幣當日升貶的可能原因（外資進出台股、出口商拋匯、壽險避險、央行動向等），**只寫有新聞或數據佐證的，每一項附來源**；沒有就給 `[]`。
- `holders`：對持有美股 ETF、美元存款、台股的人各一句話。
- `foreign`：外資買賣超有資料才寫（net、date、src 三個都要），沒有就 `null`，不可估計。
- 不要自己填任何數字欄位；資料抓不到時程式會留空，網頁顯示「資料暫缺」。
- 文字不得提到本站任何模型、策略、持倉或訊號。
- 情境和現在的數字明顯矛盾（例如選 `usd_exit` 但美元指數是漲的）會被擋下，請依最新數字重新判斷。
- 沿用舊底稿更新（例如盤中大漲大跌版）時，也要依最新數字重新檢視 scenario 與 basis。

## 數字怎麼算（scripts/daily_fx.py）
- 來源：heatmap-live 分支 us.json、tw.json 的報價板 `mb`（Yahoo Finance；加權指數為 Yahoo奇摩股市）。兩個檔都有時用報價時間較新的。
- 單日漲跌＝最新價÷前一交易日收盤−1；近一週漲跌＝最新價÷上週最後一個交易日收盤−1；殖利率用相減（百分點）。
- 台幣報酬（網頁現算）≈ 美元資產漲跌＋美元兌台幣漲跌（近似式，忽略兩者相乘的小項）。
