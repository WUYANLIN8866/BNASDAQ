帳號管理

網站寫入權限（只需設定一次）

本站沒有伺服器；新增／修改／刪除帳號與公告時，網頁會在背景直接存到網站的 GitHub 儲存庫，你不用開 GitHub。只需要第一次設定一把存取權杖（PAT）：存好後會用你的管理員金鑰加密、跟著管理員帳號走，之後在任何裝置登入管理員都能直接新增、修改、刪除。權杖到期或被撤銷時才需要重貼。

  1. 按「在 GitHub 建立權杖」（名稱、期限 366 天、Contents 與 Actions 的讀寫權限都已幫你填好）
  2. 在 Repository access 選 Only select repositories → 選 BNASDAQ（這一步 GitHub 不讓網址預先填）
  3. 按最下面 Generate token，複製 github_pat_…（只顯示這一次）
  4. 貼進下面的框，按「測試並儲存」

會員規則金鑰（一次性設定）

設定一次後，專案 B 區的策略只要有變更，系統就能自動把新規則加密發布到會員專區，不必再經過你的瀏覽器。做法：這台瀏覽器產生一組 RSA 金鑰；公鑰公開（只能用來加密），私鑰先用你的會員主金鑰加密才存到 GitHub，所以只有登入的會員解得開。

會員資產跨裝置同步（一次性設定）

啟用後，會員在任何裝置新增或修改「會員持有資產」，都會自動同步到他登入的每一台裝置。本站沒有伺服器，所以同步資料放在你另一個私人 GitHub repo；每位會員的資料先用他的登入密碼導出的金鑰加密才上傳，repo 裡只有密文，也看不出哪一份是誰的。

  1. 在 GitHub 建一個私人（Private）repo，建議命名 BNASDAQ-sync，並勾選「Add a README file」。
  2. 建一把新的 fine-grained personal access token：Repository access 選「Only select repositories」，只選剛建的那個 repo → Permissions：Contents: Read and write。不要用上面那把管理用的 PAT。
  3. 把 repo 名稱和 token 貼到下面，按「檢查並啟用」。
